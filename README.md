# すくすく（SuQSuQ）

生まれて◯日・生後◯か月・妊娠◯週を、写真や動画にそのまま入れて残すツール。名前は「すくすく」の「く」を Q にした、コネクト〜ConneQt〜の仲間。キャッチコピーは「すくすく、まいにちが記念日」。

まだ確認中（noindex。ConneQt の一覧・ポートフォリオには載せていない。GitHub にもまだ上げていない）。

## 使い方

1. 上のタブで「👶 生まれてから」か「🤰 おなかの中」
2. なまえ（なくてもよい）と、生まれた日／出産予定日を入れる。いまの数えと、つぎの節目が出る
3. 「🎨 写真に入れる文字」で形を決める（見本の上で、文字を指で動かせる。2本指で大きさ）
4. 「📷 カメラを開く」で撮る（写真／動画）。「🖼 写真を選ぶ」で、撮っておいた写真にも入れられる
5. できたら「📤 保存・共有」（共有できない端末は ⬇️ ダウンロード）

- 数える日：前に撮った写真に入れるときは「📅 数える日」をその日に（次に開いたときは、きょうにもどる）
- 生まれた日を「1日目」と数える（オン）／0日と数える（オフ）
- 撮る画面の 🎨 で、映像を見ながら形を変えられる（はじめの画面の欄をそのまま下のシートに移している）

## 表示の選び方

| タブ | 選べるもの | 例 |
|---|---|---|
| 生まれてから | 100 Days／100日目／3か月 8日／1さい 2か月 | 1さい前は「生後◯か月」、1か月前は「◯日目」 |
| おなかの中 | 24週 3日／24w3d／あと◯日 | 予定日を 40週0日 として数える |

## 文字の形（js/draw.js）

- テンプレート（TEMPLATES）：ふんわり・ポップ・てがき・エレガント・まるバッジ・フレーム。字（Google Fonts）・位置・飾りがテンプレートごと
- 色・大きさ・位置（指で動かす）・いっしょに入れる（なまえ・日付）
- 動くスタンプ（STAMPS）：✨ キラキラ・💗 ハート・🫧 しゃぼん玉・🌸 はなびら・⭐ ほし・🎊 紙ふぶき・🎈 ふうせん（いくつでも。写真では止まった形）
- 文字の動き（MOTIONS。動画のとき）：ふわふわ・ぽよん・カウントアップ（1 からその数まで）・なみ
- マイテンプレート：いまの形（テンプレート・色・位置・大きさ・スタンプ・動き）に名前をつけて8つまで。長押しで消す

## しくみ

映像（または選んだ写真）・スタンプ・文字を1つのキャンバスに描く（ろくがと同じ形）。写真は同じ絵を 1080 の大きさで画像に、動画はそのキャンバス（＋マイクの音）を MediaRecorder で録る（iPhone は mp4、Android・パソコンは webm のことが多い）。画面の形は 9:16・3:4・1:1・16:9。

写真・動画も、入れた日付・なまえも、この端末の中だけ（localStorage の `suqsuq:state`）。サーバーには送らない。

## ファイル

- index.html・style.css：画面（部品はおくるんの Q キット `https://katsuan.github.io/line-share/shared/ui.css`。色は style.css の :root でピーチ）
- js/：core.js 共通・state・日数の計算 ／ draw.js 描く（テンプレート・スタンプ・動き） ／ setup.js はじめの画面 ／ shoot.js 撮る画面 ／ main.js 最初の表示と毎フレームの描画
- tools/icon.py：アイコン・ロゴ・OGP（おくるんの tools/brandkit.py。ピーチの角丸に、ふたばの芽が出た Q）
