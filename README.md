# すくすく（SuQSuQ）

生まれて◯日・生後◯か月・妊娠◯週を、写真や動画にそのまま入れて残すツール。名前は「すくすく」の「く」を Q にした、コネクト〜ConneQt〜の仲間。横ロゴは「SuQ²」（SuQ の2乗で SuQSuQ）。キャッチコピーは「すくすく、まいにちが記念日」。

公開URL: https://katsuan.github.io/suqsuq/ （2026-10-23 公開。ConneQt の一覧（line-share の data/hub-links.json の key "suqsuq"）・ポートフォリオに載せた。はじめの画面のいちばん下に「📤 すくすくを紹介する」と仲間のアイコン列（line-share の shared/tool-share.js））

## 使い方

1. 上のタブで「👶 生まれてから」か「🤰 おなかの中」
2. なまえ（なくてもよい）と、生まれた日／出産予定日を入れる。いまの数えと、つぎの節目が出る
3. 「🎨 写真に入れる文字」で形を決める（見本の上で、文字を指で動かせる。2本指で大きさ）。欄は「🎨 形／✏️ 文字／✨ かざり／💾 保存」のタブに分けてあり、見本は上に止まったまま（変えながら見られる）
4. 「📷 カメラを開く」で撮る（写真／動画）。「🖼 写真を選ぶ」で、撮っておいた写真にも入れられる
5. できたら「📤 保存・共有」（共有できない端末は ⬇️ ダウンロード）
   - 保存するのは、いつも文字・スタンプ入り。「🎨 写真に入れる文字」のいちばん下の「保存」で「加工なしの元の写真・動画も残す」をオンにすると、できた画面に「📤 加工なしも保存」も出る（カメラで撮ったときだけ）。写真はカメラの元の大きさ（切らない・左右もそのまま）、動画はカメラの映像を、もう1つの録画でそのまま録る（同じ音）。ファイル名の最後に -raw
6. 「🔔 節目をカレンダーに」：これからの節目（お七夜・生後◯か月・100日・ハーフバースデー・誕生日／妊娠16・20・28・36・37・40週。毎週も選べる）を、まとめてカレンダーのファイル（.ics。お知らせは当日の朝9時・前の日の夜8時・なし）か、1件ずつ Google カレンダーに（js/calendar.js）

- 数える日：前に撮った写真に入れるときは「📅 数える日」をその日に（次に開いたときは、きょうにもどる）
- 生まれた日を「1日目」と数える（オン）／0日と数える（オフ）
- 👶 うまれたときの記録（生まれてから）：時刻・体重・身長を入れると、数字の下に「3,120g ・ 49.5cm ・ 4:32 生まれ」（バースフォトの定番）
- ひとこと：好きな文字（24字まで。「はじめての寝がえり」など）を数字の上に。下の例（はじめまして・お食い初め・ハーフバースデー・安定期に入りました など。数えかたで変わる）を押すと入る
- おすすめの組み合わせ：押すと、テンプレート・色・スタンプ・動き・ひとことをまとめて入れる見本（お食い初め・ハーフバースデー・1さいの誕生日・マタニティ など。js/setup.js の RECIPES）。そこから好きに変えられる
- うまれたときの記録の体重は、3.12 のように kg で入れても 3,120g になる
- 撮る画面の下：🖼 写真を選ぶ／◐ 重ねる（前に撮った写真をうっすら重ねて、同じ向き・大きさで撮る。画面に重ねるだけで写真・動画には入らない）／シャッター／⏱ セルフタイマー（なし・3秒・10秒。動画は録りはじめ。数えている途中で押すとやめる）／🔄 カメラの切りかえ
- 撮る画面の 🎨 で、映像を見ながら形を変えられる（はじめの画面の欄をそのまま下のシートに移している。シートを開くと映像はシートの上に小さくなり、全部見える）
- 日付をまだ入れていないと、下のボタンは「📅 まず日付を入れる」。押すと日付の欄へ
- ⏳ くろのすで数える（いまの数えの下）：おなかの中は「👶 出産予定日まで」、生まれてからは「🎉 つぎの節目まで」「🎂 毎年の誕生日」。くろのすのページを、日付・なまえ（「はるとの誕生日」「ひなに会える日」）を入れた形で開く（js/calendar.js の qronosLinks）
- きょう以外の日で数えているときは、撮る画面に「📅 ◯ で数えています」（写真・動画には入らない）

## リンクで日付を渡す

`?birth=2026-07-14`（生まれた日）／`?due=2027-03-01`（出産予定日）、`&name=はると` も。開くとその日付・なまえが入り、アドレスからは消える。くろのすの「その日から」「毎年の記念日（年あり）」のページの「🌱 すくすくで写真に入れる」から使う。

## 文字の形（js/draw.js）

- テンプレート（TEMPLATES）：ふんわり・ポップ・てがき・エレガント・まるバッジ・フレーム。字（Google Fonts）・位置・飾りがテンプレートごと
- 色（8色と、好きな色）・大きさ・位置（指で動かす）・いっしょに入れる（なまえ・日付・うまれたときの記録）
- 動くスタンプ（STAMPS）：✨ キラキラ・💗 ハート・🫧 しゃぼん玉・🌸 はなびら・⭐ ほし・🎊 紙ふぶき・🎈 ふうせん（いくつでも。写真では止まった形）
- 文字の動き（MOTIONS。動画のとき）：ふわふわ・ぽよん・カウントアップ（1 からその数まで）・なみ
- マイテンプレート：いまの形（テンプレート・色・位置・大きさ・スタンプ・動き）に名前をつけて8つまで。長押しで消す

## しくみ

映像（または選んだ写真）・スタンプ・文字を1つのキャンバスに描く（ろくがと同じ形）。写真は同じ絵を 1080 の大きさで画像に、動画はそのキャンバス（＋マイクの音）を MediaRecorder で録る（iPhone は mp4、Android・パソコンは webm のことが多い）。画面の形は 9:16・3:4・1:1・16:9。

写真・動画も、入れた日付・なまえも、この端末の中だけ（localStorage の `suqsuq:state`）。サーバーには送らない。

- 節目のお知らせ：GitHub Pages だけでは送れない（下の「節目のお知らせ」）

## 節目のお知らせ（メモ）

ページを閉じているときに知らせるには、決まった時間に送る係（サーバー）がいる。GitHub Pages は置いてあるだけなので、Web Push はそれだけではできない。案：

- カレンダーに入れる（.ics・Google カレンダーのリンク）：サーバーいらず。カレンダーの通知で知らせる。くろのすの calendarLinks と同じ形（← 2026-10-22 に作った）
- LINE で送る：かぞく（KAZOQ）の GAS ボットにはもう妊娠週のメッセージがある（01_12_PREGNANCY_WEEK_MESSAGE_MASTER）。そこに節目を足す
- アプリ版：端末の中だけの通知（ローカル通知）でできる。サーバーいらず
- Web Push：ホーム画面に追加したときだけ（iPhone は iOS 16.4 から）。送る係に Cloudflare Workers の定期実行などがいる
